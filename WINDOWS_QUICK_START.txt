📋 WHAT TO DO - STEP BY STEP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

IMPORTANT: You need TWO terminal windows open at the same time!


🟢 STEP 1: Open First Terminal Window
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Click Start menu → Type "Command Prompt" → Press Enter

Or press: Windows Key + R → Type "cmd" → Press Enter


🟢 STEP 2: Start Backend in First Terminal
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Copy & Paste this into the command prompt:

    cd backend
    python run-backend-complete.bat


✅ YOU SHOULD SEE:

    [STEP 1] Checking Python Installation...
    [STEP 2] Navigating to backend directory...
    [STEP 3] Setting up Python Virtual Environment...
    [STEP 4] Activating Virtual Environment...
    [STEP 5] Upgrading pip...
    [STEP 6] Installing Python dependencies...
    [STEP 7] Running diagnostic checks...
    
    INFO:     Application startup complete
    INFO:     Uvicorn running on http://0.0.0.0:8000


⚠️  IF YOU SEE ERRORS:

    • Read the error message carefully
    • Check TROUBLESHOOTING.md for solutions
    • Try: reset-everything.bat


🟢 STEP 3: Open Second Terminal Window (KEEP FIRST ONE OPEN!)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Click Start menu → Type "Command Prompt" → Press Enter

Or press: Windows Key + R → Type "cmd" → Press Enter


🟢 STEP 4: Start Frontend in Second Terminal
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Copy & Paste this:

    npm run dev


✅ YOU SHOULD SEE:

    VITE v... dev server running at:
    
    ➜  Local:   http://localhost:5173/


⚠️  IF npm command not found:

    • Download Node.js from: https://nodejs.org/
    • Install it and restart this terminal
    • Try again: npm run dev


🟢 STEP 5: Open Your Browser
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open any browser and go to:

    http://localhost:5173


✅ YOU SHOULD SEE:

    StudyGen AI Dashboard
    (or login page if not logged in)


🟢 STEP 6: Verify Everything Works
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. In browser, press F12 (open developer tools)
2. Click "Console" tab
3. Look for: [API] GET /api/dashboard/overview
4. It should say: Response: 200


✅ IF YOU SEE THIS:

    [API] GET /api/dashboard/overview
    [API] Response: 200

    SUCCESS! Everything is working! 🎉


⚠️  IF YOU SEE ERRORS:

    Check the error message in the console
    Look it up in: TROUBLESHOOTING.md
    Follow the exact steps to fix

💡 PRO TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. KEEP BOTH TERMINALS OPEN
   • First terminal: Backend running
   • Second terminal: Frontend running
   • Don't close them while working!

2. AUTO-RELOAD WORKS
   • Edit frontend code → Browser auto-refreshes
   • Edit backend code → Uvicorn auto-reloads
   • No manual restarts needed!

3. CHECK LOGS FIRST
   • Backend terminal shows all server errors
   • Browser console (F12) shows frontend errors
   • Database issues appear in backend terminal

4. BROWSER DEVELOPER TOOLS (F12)
   • Console tab: Shows API calls and errors
   • Network tab: Shows HTTP requests/responses
   • Application tab: Shows localStorage & cookies

5. USE BROWSER REFRESH
   • Sometimes just F5 (refresh) fixes things
   • Hard refresh: Ctrl+Shift+R (clears cache)
