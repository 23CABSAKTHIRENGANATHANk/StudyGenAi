 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Network error loading dashboard"

   ✓ Step 1: Is the backend running?
   
     Windows: Check if start-backend.bat window is open and shows
              "Uvicorn running on http://0.0.0.0:8000"
     
     Mac/Linux: Check if backend terminal shows port 8000 listening
     
   ✓ Step 2: Test backend health
   
     Run in terminal: curl http://localhost:8000/
     
     Expected response:
     {"status":"ok","service":"StudyGen AI Backend","version":"0.1.0"}
   
   ✓ Step 3: Click the "Retry" button on the error message
   
   ✓ Step 4: Check browser console (F12 → Console tab)
   
     Look for: [API] GET /api/dashboard/overview
     
     If you see CORS or connection errors, backend is not accessible

❌ "Port 8000 is already in use"

   Windows: 
   netstat -ano | findstr :8000
   taskkill /PID <PID> /F
   
   Mac/Linux:
   lsof -i :8000
   kill -9 <PID>

❌ "Cannot find module 'react'" (Frontend)

   Windows: Run "npm install" in the frontend directory
   Mac/Linux: Same as above

❌ "ModuleNotFoundError" (Backend)

   Windows: Run "pip install -r requirements.txt" in backend/
   Mac/Linux: Same as above
